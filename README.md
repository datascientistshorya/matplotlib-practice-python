📊 Matplotlib Practice in Python

This repository contains my hands-on practice notebooks for learning and mastering data visualization using Matplotlib in Python.
It focuses on building strong visualization fundamentals that are essential for Exploratory Data Analysis (EDA) and data storytelling.

🚀 What This Repository Covers

Through these notebooks, I practice:

Line charts

Bar charts

Scatter plots

Histograms

Plot customization (titles, labels, colors, styles)

Figure sizing and layout control

Basic visualization best practices

The goal is to strengthen practical visualization skills used in real-world data analysis and machine learning projects.

📁 Files in This Repository
✅ MAtplotLib.ipynb

Introductory notebook covering basic Matplotlib concepts and simple plots.

✅ chartpractice.ipynb

Practice notebook focused on experimenting with different chart types and parameters.

✅ chart2.ipynb

Extended exercises exploring plot customization and formatting.

✅ chart_new.ipynb

Additional visualization practice to reinforce concepts and improve plotting confidence.
